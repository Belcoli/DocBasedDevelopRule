# 插件设计基线

状态：设计已确认，包含随后确认的主契约权威、插件独立性、辅助材料可选、多主契约及设计内容边界约束。本文约束插件的制作；不替任何使用它的项目定义设计。

## 目标与非目标

提供可迁移的开发 guideline、流程与方法论，使 AI 与开发者能够通过项目文档确定有效设计、真实进度、未决问题、授权及证据边界。

插件不依赖任何现有项目，不引用实际项目作为示例，不存放使用方的契约实例、进度、Issue、主机路径或日志。不提供云同步、协作平台、文档数据库或技术强制执行器。

## 已确认方案及取舍

选择一个主技能入口，按任务加载规则、场景指引和模板。曾比较多个专用技能入口：其操作分类更直接，但增加触发重叠与入口维护。本期采用单入口，共享规则只维护一份。

全局安装，项目明确接入一次，后续相关任务遵循。安装本身不等于项目接入，项目接入也不扩大每次任务的修改授权。

一个 GitHub 源码仓库维护一个 Codex 插件包。桌面端为必需目标，CLI 共用内容但单独验证；IDE 扩展不纳入本期支持。

## 设计权威

主契约是项目一切有效设计的唯一权威说明，覆盖职责、边界、文件与组件组织、接口签名及行为、状态与数据流、不变量和异常语义。项目可以维护一份或多份主契约；唯一权威指每条设计的归属唯一，不限制文件数量。各契约声明覆盖范围，尽量避免覆盖相同模块或重复描述相同内容；共用设计只定义一处，其他契约引用，主契约之间不得存在内容冲突。

主契约对其中记录的每个接口说明三组内容：明确名称/签名、输入输出、前后条件、错误和副作用；接口内部的简要逻辑、状态与数据流；接口内部变量与入参的生命周期。生命周期包括来源/创建、持有与所有权、使用和变化范围、结束或释放，以及是否跨越调用返回、异步阶段或后续调用。可将生命周期相同的变量分组说明，但应明确覆盖对象；模块级概述不能替代接口逐项说明。

主契约聚焦设计，不定义验收要求、验收标准、验证步骤或证据要求。验收在主契约之外按项目既有方式或本次明确沟通约定，不强制新增验收文档；验收约定不能替代或修改设计定义。实际执行与验收结果由 Progress 记录。

非目标不是主契约必填内容。只有开发者明确强调某条目的非目标，或明确批准/赞同建议的非目标时，才记录该内容；不得根据未提及、未实现或对其他条款的认可推测非目标。没有此类明确确认时省略，不视为设计缺项。

Progress 和 Issues 不包含设计说明、接口定义、替代方案或设计结论。它们通过稳定编号和链接引用主契约，不复制设计正文，也不能覆盖、解释或削弱主契约。Issue 的门禁限制工作推进，不改变设计。

未确认设计可以直接在对话中讨论；项目选择留存方案时，提案须明确标记为非生效。用户确认后更新对应主契约；已有提案按项目约定标记归并或归档。必要确认依据可在主契约中简短说明，不要求另建历史文件，不建立第二份当前设计。最新明确的用户决策优先指导契约修订；不得用尚未同步的旧条款反对已确认的新决策，也不得让新旧规则继续并存。

设计提案、历史/决策记录、调查/审核/证据附件均为可选辅助材料。项目自行决定是否以文档形式保存，不要求建立这些文件、占位入口或独立报告，也不能因缺少它们而阻断工作；有效设计、实际进度和未决事项仍分别维护在主契约、Progress 和 Issues 中。

## 核心与项目策略

核心固定文档分工、契约先行、授权边界、局部门禁、证据语义和一致性维护。项目决定目录、责任分工、编号、验证方式、QA 分界、诊断工具及归档方式；项目策略不得放入功能设计或削弱核心边界。

项目自行维护所有项目文档。插件更新不自动迁移、覆盖或改写项目文档；项目事实只可用于当前项目，不反向写入插件。插件方法改进须是独立授权的维护任务，并使用重新构造的通用案例。

## 任务与状态

调查、解释和审核不自动授权修改。已授权且契约不变的小任务直接实施并作相称验证；改变接口、职责或重要语义时先讨论并确认契约。文案等低影响任务只更新相关文件，不强制创建整个文档体系。

契约确认与实施授权分别识别；明确的实施指令可以同时提供两者。实现状态、不同验证方式及未决问题保持独立。历史验收保留，增量只重开受影响部分。

P0 阻止当前约定范围后续实施并允许解阻工作；P1 仅阻断明确依赖项；P2 在安全替代边界内延期，到指定阶段必须处理；P3 为非阻断观察。不能用 TODO 绕过门禁。

## 文档与可移植性

项目采用声明指向文档入口；入口管理职责映射，契约管理设计，Progress 管执行与验证，Issues 管未决事项。首次接入先识别映射，不搬迁或重建已有体系。

主机路径留在项目本地绑定信息中。包内使用相对链接；迁移只重新定位项目根、文档根和客户端安装位置。运行流程无其他技能、MCP、特定 shell 或专属 API 依赖。

## 交付范围

交付技能入口、通用规范、接入/开发/审核交接指引、空白模板、安装迁移和维护说明、通用场景与验证记录。

## 制作时的具体选择

- 插件与技能标识：`document-first-development`；初始版本：`0.1.0`。
- 正文与模板使用中文，机器标识使用英文。
- 插件采用当前 Codex 支持的 `.codex-plugin/plugin.json` 清单；仓库 marketplace 指向独立插件目录。
- 安装指南与维护记录位于仓库侧，技能运行内容全部封装在插件内部。
- 不自动提交、推送、发布或安装到用户现有插件环境。
