# 可复制模板

这些是空白材料，不是任何项目的实例。先识别已有文件；只把需要的模板复制到用户确认的项目文档位置，并替换占位符。不要在插件内填写，不批量制造空文档。

| 需要什么 | 模板 |
|---|---|
| 文档职责映射与模块入口 | [文档索引](index.md) |
| 项目自己的工作方式与主机定位策略 | [项目适配](project-profile.md) |
| 目标、约束与需求输入 | [需求](requirements.md) |
| 模块有效设计及确认依据 | [主契约](master-contract.md) |
| 实际执行与分方式验证 | [Progress](progress.md) |
| 未决问题与局部门禁 | [Issues](issues.md) |
| 交付范围、拆分与依赖 | [里程碑](milestones.md) |
| 可选：项目需要留存尚未确认的设计讨论 | [非生效提案](design-proposal.md) |
| 可选：项目需要独立留存确认依据与替代关系 | [决策历史](decision-history.md) |

设计提案、历史/决策记录、调查/审核/证据附件均可不建；讨论或审核可直接在对话中完成。主契约模板可按实际职责用于一份或多份文档，各自声明范围，同一设计只定义一处且互不冲突。

主契约模板为每个接口提供调用约定、内部逻辑与状态/数据流、入参及内部变量生命周期三组说明；模块级概述不替代逐接口说明。模板只承载设计，不包含验收要求。非目标不设默认占位字段，只有开发者明确提出或明确批准/赞同建议时才记录。

字段可按规模删减；不能删除核心权威、授权和证据边界。路径、编号、术语、责任人及验证工具由项目决定。占位符不代表已确认事实；缺少必要信息时标为未确认。

职责与维护要求见 [文档职责](../../references/documents.md)。模板里的说明用于指导填写；复制后保留有用说明，删除不适用栏目。
