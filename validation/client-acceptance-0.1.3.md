## 环境前置失败与未覆盖部分

1. CLI 最初在外层受限执行环境中无法写入用户运行状态；按标准权限机制重试后可启动真实模型会话。
2. 默认 elevated Windows 沙箱随后出现 `CreateProcessWithLogonW failed: 1385`，导致项目读取失败。技能入口加载成功与任务未完成分别记录，不以会话 exit 0 判定通过。
3. 按 [官方 Windows 沙箱说明](https://learn.chatgpt.com/docs/windows/windows-sandbox) 执行一次性 MXC 兼容性探针，返回 MXC_OK、exit 0；再以相同受限工作区权限执行上述 CLI 用例。未更改保存的沙箱配置、操作系统安全策略，未使用关闭沙箱的模式。通过结论限定于 MXC；默认 elevated 的问题仍未修复。
4. 安装前已运行聊天派生出的两个全新子代理上下文没有看到新增技能。其普通审核结果不计作插件通过；真正的新桌面聊天随后成功加载。此差异不单独证明插件缺陷或特定缓存机制。
5. 桌面插件目录页、可见启用控件及鼠标点击安装流程未执行：本次 UI 自动化工具不允许操作宿主桌面应用自身。无截图或界面操作证据，后台启用状态不能替代这些项。
6. 桌面端仅项目采用声明、没有显式技能调用的新聊天链尚未单独验证；CLI 的对应结果不能代替桌面结果。
7. 尚未逐项执行全部 23 个构造场景，也未在第二台主机验证安装迁移。本轮未发现需要修改 0.1.3 规则或模板的问题，不代表不存在其他问题。
